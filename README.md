# Quantum Pong

A playable, dependency-free browser game featuring transverse quantum wave propagation, interferometric phase obstacles, Born-rule paddle measurements, luminous collapse animations, and a stochastic computer opponent.

## Play locally

Open `index.html` in a modern web browser. No build system, package installation, internet connection, or backend is required.

If your browser blocks direct file access, start a local static server:

```bash
cd quantum-pong
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish to GitHub Pages

1. In this repository open **Settings → Pages**.
2. Choose **Deploy from a branch**, set branch to **main** and directory to **/(root)**, and save.
3. After GitHub Pages finishes deploying, play at **https://zehsilva.github.io/qpong/**.

Source code: https://github.com/zehsilva/qpong

## Controls

- Move mouse vertically in the arena to move the left (cyan) paddle.
- On touch devices, drag on the left portion of the arena to move the paddle.
- **W/S** or **Up/Down** moves the paddle with the keyboard.
- Choose a Tetris piece from the queue (or press **1**, **2**, **3**) and click/tap in the central dashed zone to deploy it.
- **Space** pauses/resumes.
- Toggle and adjust the *Transparent interference overlay* in the control panel.
- Audio is generated by Web Audio on user input. It requires a user gesture in modern browsers.

## Physics model

The horizontal wavefront location `x(t)` is classical. The transverse complex wavefunction `ψ(y,t)` is represented on 256 sites and propagated under

`i ∂ψ/∂t = -D ∂²ψ/∂y²`,

using spectral propagation on an even mirrored 512-site extension, which gives reflecting (Neumann) boundaries at the top and bottom. Each deployed obstacle acts as a diagonal unitary phase operator `ψ(y) → exp(i φ_obstacle(y)) ψ(y)` at a designated `x` plane. Splitters use a localized cosine phase grating, yielding diffracted orders as the state propagates.

When the wave reaches the paddle plane, a position `y*` is sampled from the discrete Born distribution `|ψ(y)|²`. The sample produces a successful return precisely when it lies within the paddle's detector interval. A successful return prepares a fresh localized Gaussian packet, with an outgoing transverse phase gradient set by paddle contact position and motion. The collapse animation is a visualization of the measurement, not an additional unitary evolution.

The agent extrapolates the current complex state to its paddle (including known phase screens), computes the probability mass covered by candidate paddle positions, and stochastically chooses a target using a softmax policy. Temperature, movement speed, and aiming noise depend on the selected difficulty. The agent also occasionally adds obstacles.

The interference overlay shows **local probability-fringe contrast** (a high-pass difference between Born density and a locally smoothed density). It is a useful visual indicator of oscillatory interference patterns, **not** a formal phase-coherence measure or a separation of amplitudes into individual paths. The density heatmap, rather than the overlay, is the detector's authoritative probability distribution.

## Known simplifications

- This is a 1+1D paraxial, quantum-inspired wave model, not a two-dimensional quantum scattering simulation.
- Detection at the paddle plane is a single idealized measurement event.
- Obstacles are phase masks rather than hard classical collisions.
- A successful measurement prepares a new Gaussian state, idealizing the paddle's reflection/re-emission.
- The translucent field surrounding the active wavefront shows free propagation backward/forward from the active transverse state; future obstacle effects are only included in the discrete goal forecast and actual evolution, not every rendering slice.

Everything runs client-side; no personal data leaves the browser.
